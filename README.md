One emoji, nothing else: 🫶 — two hands shaping a heart, offered to a stranger.

Heart hands read as warm at first glance, need no words or context, and carry no joke that could land wrong. They are a small, deliberate gesture of kindness from someone unknown — chosen, not the first smiley that comes to mind.

## Run it

```sh
node main.ts
```

The program reads `one-emoji.txt`, checks it holds exactly one emoji, and writes it to `/output/entry.txt`.
